# Benghazi Wheels Launch

Build a complete modern, high-converting, fully responsive English landing page for Libyan Road Company, premier importer and wholesale distributor of automotive spare parts, tires, batteries, and lubricants in Benghazi, Libya. Implement the supplied page structure, exact brand direction, realistic copy, responsive sticky navigation with mobile menu, smooth-scroll/contact CTAs, product/value cards, partner standards, RFQ form, map-style location area, and footer. Use the requested navy/steel-blue/amber industrial-modern visual language with subtle road and tire-tread motifs.
